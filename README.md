# TP NLP — Traitement du langage naturel

## Description
Ce projet a pour objectif de découvrir les techniques fondamentales du traitement automatique du langage naturel (NLP) avec Python.

## Objectifs
- Nettoyer et prétraiter un texte.
- Convertir le texte en minuscules.
- Supprimer la ponctuation.
- Tokeniser les phrases.
- Éliminer les mots vides (*stopwords*).
- Lemmatiser les mots avec NLTK et spaCy.
- Représenter les textes sous forme numérique avec Bag of Words et TF-IDF.

## Bibliothèques utilisées
- Python
- NLTK
- spaCy
- Scikit-learn

## Fichier principal
- `TP11_NLP.ipynb` : notebook Jupyter contenant les exercices, le code Python et les résultats du TP.

## Installation
Installer les bibliothèques nécessaires avec la commande :

```bash
pip install nltk spacy scikit-learn
```

## Exécution
Ouvrir `TP11_NLP.ipynb` avec Jupyter Notebook ou JupyterLab, puis exécuter les cellules dans l'ordre.
